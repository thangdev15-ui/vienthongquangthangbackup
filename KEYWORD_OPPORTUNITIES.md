## Publishing rules

1. Improve the existing URL when it matches the search intent; do not create a near-duplicate URL.
2. Give each guide one primary intent and link to genuinely relevant category/product pages.
3. Use real stock, specs, warranty and compatibility data only.
4. Add unique evidence: project photos, wiring diagrams, test notes, data sheets or FAQs answered by a technical reviewer.
5. Review 28-day GSC data before deciding whether to expand a cluster.
